## البنية

```
content/site.json        إعدادات الموقع ونصوصه
content/posts/           التدوينات، ملف .md لكل تدوينة
content/notes.md         الدفتر: سطور قصيرة مرقّمة
content/pages/now.md     صفحة «الآن»
content/pages/about.md   صفحة «عني»
theme/style.css          التصميم كله
assets/images/           الصور
assets/og/               بطاقات المشاركة (تُولَّد)
assets/mail/             صور رسائل البريد (تُولَّد)
mail/                    رسالة «تدوينة جديدة» لكل تدوينة (تُولَّد)
build.py                 المولّد
tools/og.mjs             مصوّر بطاقات المشاركة
dist/                    الموقع الجاهز للنشر (يُولَّد، لا يُعدَّل باليد)
```

## إضافة تدوينة

ملف في `content/posts` باسم مثل `2026-11-20-my-post.md`، يبدأ هكذا:

```
---
title: عنوان التدوينة
excerpt: جملة أو جملتان تظهران في الرئيسية وعند مشاركة الرابط.
topic: اسم الموضوع (اختياري)
image: assets/images/name.jpg (اختياري، صورة رأس التدوينة)
---
```

صورة داخل النص: `![وصف](assets/images/name.jpg "تعليق اختياري")`. كل الصور تأخذ صبغة الموقع تلقائيًا.

## إضافة سطر إلى الدفتر

في أعلى `content/notes.md`، تحت الترويسة:

```
## 2026-11-20
نص السطر.
```

## البناء

```
python3 build.py --og     يجهّز بطاقات المشاركة
node tools/og.mjs         يصوّرها (يحتاج Playwright)
python3 build.py          يبني الموقع في dist/
```

بطاقات المشاركة تحتاج خطوتيها الأوليين عند كل تدوينة جديدة فقط.

## رسالة «تدوينة جديدة»

كل بناء يكتب في `mail/` رسالة بريد جاهزة لكل تدوينة: صورة الرأس مصبوغة، والعنوان، وفقرة أو فقرتان، وزر «اقرأ التدوينة كاملة». النص يؤخذ من حقل `teaser` في رأس التدوينة (الفقرات يفصلها `|`)، وإن غاب أُخذ من `excerpt`.

الرسالة تحتاج `url` في site.json لتعمل روابطها وصورها خارج حاسبك. ملفات `mail/` لا تُنشر مع الموقع.

## مفاتيح site.json

| المفتاح | وظيفته |
|---|---|
| `thirtieth_birthday` | تاريخ بلوغك الثلاثين: `"2024"` أو `"2024-05"`. حين يُملأ يصير الأرشيف «سنوات الثلاثين» وتُرتَّب التدوينات حسب عمرك. فارغ: أرشيف حسب السنة. |
| `years_notes` | سطر يلخّص كل سنة: `{"31": "…", "32": "…"}`. |
| `reply_email` | بريدك. حين يُملأ يظهر سطر «اكتب لي» في آخر كل تدوينة. |
| `image_treatment` | `false` يوقف صبغ الصور. |
| `url` | عنوان الموقع الكامل بعد النشر. يفعّل RSS وخريطة الموقع وبطاقات المشاركة والتحميل المسبق. |
| `newsletter.enabled` | `true` يعيد صفحة النشرة وأزرار الاشتراك، ويحتاج `form_action` أو `url` من أداة النشرة. |
| `hero` و`manifesto` | نصوص الرئيسية. |

## ما ينتظر إكماله

- `years_notes`: سطر يلخّص كل سنة من سنوات الثلاثين (اختياري).
- `content/pages/about.md` و`content/pages/now.md`: هيكلان ينتظران نصك.
- نصوص الهيرو والفقرة التعريفية ووصف الدفتر: مسودات تنتظر مراجعتك.
- `reply_email`.
- التدوينات الثلاث وسطور الدفتر الثلاثة والصورتان في `assets/images` نماذج تجريبية، تُحذف عند أول محتوى حقيقي.
- النشر على GitHub، ثم ملء `url`.
